# Fälle im Lernapp-Baukasten – Übersicht

Jeder Fall vermittelt **eine** zentrale optische Lernbotschaft. Aufbau in der App:
Einstieg (mit Steckbrief) → Ausgangsform → Zielwirkung → Schnittentscheidung →
(mögliche Richtungen) → Warum es wirkt → Worauf achten → Verständnis-Check → Merksatz.

Lösungen sind immer als **mögliche gestalterische Richtungen** formuliert, nie als starre Regel.

---

## 1. Nase im Profil

| | |
|---|---|
| **Beobachtung** | Die Nase wirkt in der Seitenansicht groß, lang oder markant. |
| **Zielwirkung** | Die Seitenansicht soll ausgeglichener wirken. |
| **Was bleibt fix** | Nase und vorderes Profil. |
| **Was wird variiert** | Hinterkopf, Oberkopf, Ponyführung, Bewegtheit der Haarform. |
| **Lernbotschaft** | Nicht die Nase verändert sich, sondern das Verhältnis in der Gesamtform. |
| **Worauf achten** | Keine starre Regel. Nicht jede markante Nase braucht dieselbe Lösung. |
| **Merksatz** | Nicht die Nase ändert sich, sondern das Verhältnis. |

- **Baukasten-Elemente:** Profil-Lehrgrafik mit fixer Nase (Akzentfarbe), Haarform-Varianten (flach, Zwischenstufe, Aufbau Hinterkopf, Höhe Oberkopf, weicher Pony, bewegte Kontur), Diagonale Nasenspitze – Ohrspitze mit Strecke vorne/hinten, Winkel-Labor (Erhebungswinkel).
- **Vergleichsansichten:** Profil (Lehrgrafik) als Hauptansicht, zusätzlich hinten und vorne.
- **Fehlerdarstellung:** Volumen zu tief (Nacken), zu hoch (nur oben), Spitze vorne, hinten flach.

## 2. Auge optisch öffnen

| | |
|---|---|
| **Beobachtung** | Ein Auge wirkt schwer, kleiner oder optisch abgesenkt. |
| **Zielwirkung** | Die Augenpartie soll offener und leichter wirken. |
| **Was bleibt fix** | Augenform und Gesichtsgrundform. |
| **Was wird variiert** | Ponyführung, Scheitel, Gewicht im Vorderbereich. |
| **Lernbotschaft** | Die Augenwirkung entsteht auch durch Linienführung rundherum. |
| **Worauf achten** | Zu schwere oder zu kurze Vorderpartien können die Wirkung verschlechtern. |
| **Merksatz** | Nicht das Auge allein entscheidet über die Wirkung, sondern auch die Linienführung rundherum. |

- **Baukasten-Elemente:** Front-Lehrgrafik mit fixen Augen (Akzentfarbe), Pony-Varianten (gerade, Zwischenstufe, schräg, seitlicher Scheitel, leichter Vorderbereich), Hilfslinien Augenachse und „Luft“ über dem Auge.
- **Vergleichsansichten:** Vorne (Lehrgrafik) als Hauptansicht, zusätzlich Profil.
- **Fehlerdarstellung:** zu schwer (liegt auf dem Lid), zu dicht, zu kurz (harte waagrechte Kante).

## 3. Doppelkinn

| | |
|---|---|
| **Beobachtung** | Die untere Gesichtspartie wirkt schwerer oder kürzer. |
| **Zielwirkung** | Das Gesicht soll gestreckter und leichter wirken. |
| **Was bleibt fix** | Kinn- und Halsbereich. |
| **Was wird variiert** | Höhe am Oberkopf, Längenführung, Volumenverteilung rund um Kiefer und Nacken. |
| **Lernbotschaft** | Auch die vertikale Formführung beeinflusst die Wirkung der unteren Gesichtspartie. |
| **Worauf achten** | Zu viel Breite oder Gewicht unten kann die Schwere verstärken. |
| **Merksatz** | Höhe und Länge strecken, Gewicht unten beschwert. |

- **Baukasten-Elemente:** Profil-Lehrgrafik mit fixem Kinn- und Halsbereich (Akzentfarbe), Haarform-Varianten (Gewicht unten, Zwischenstufe, gestreckt), Hilfslinien „Höhe“ und Linienrichtung (waagrecht / senkrecht).
- **Vergleichsansichten:** Profil als Hauptansicht (Kinn und Hals sind dort am deutlichsten). Sinnvolle Ergänzung später: vorne.
- **Fehlerdarstellung:** Volumen am Kiefer, harte Kante auf Kinnhöhe, oben flach und kurz.

## 4. Rundes Gesicht

| | |
|---|---|
| **Beobachtung** | Das Gesicht wirkt weich, breit oder kurz. |
| **Zielwirkung** | Das Gesicht soll schmaler oder gestreckter wirken. |
| **Was bleibt fix** | Gesichtsgrundform. |
| **Was wird variiert** | Länge, vertikale Linien, Seitenvolumen, Konturführung. |
| **Lernbotschaft** | Linien und Volumenverteilung verändern die wahrgenommene Gesichtsform. |
| **Worauf achten** | Zu viel Breite an den Seiten kann die Rundung verstärken. |
| **Merksatz** | Längs streckt, Breite rundet. |

- **Baukasten-Elemente:** Frontgrafik aus dem Baukasten (Gesichtsform „Rund“, Kontur in Akzentfarbe), Frisuren kurz / Volumen oben / lang / Volumen seitlich / Bob, Pony schräg oder gerade, Messlinien Stirn–Wangen–Kiefer, Oval-Schablone, Balance-Anzeige.
- **Vergleichsansichten:** Vorne als Hauptansicht. Profil bringt für diesen Fall wenig.
- **Fehlerdarstellung:** Volumen an den Seiten, kinnlange runde Kontur, gerader Pony.

## 5. Hell und Dunkel

| | |
|---|---|
| **Beobachtung** | Derselbe Schnitt wirkt unterschiedlich, je nachdem wo helle und dunkle Flächen sitzen. |
| **Zielwirkung** | Bereiche gezielt betonen oder zurücknehmen, hier: die Form nach oben strecken. |
| **Was bleibt fix** | Kopf und Schnittform. |
| **Was wird variiert** | Helle und dunkle Flächen. |
| **Lernbotschaft** | Helle Bereiche treten optisch hervor, dunkle treten zurück. |
| **Worauf achten** | Zu harte Kontraste, Gesichtsfarbe, Wunsch der Kundin oder des Kunden. |
| **Merksatz** | Helles tritt hervor, Dunkles tritt zurück. |

- **Baukasten-Elemente:** Frontgrafik mit fixer Schnittform (Akzentfarbe), Farbzonen Oberkopf / Seiten in Tonstufen, Hilfslinien mit Wirkungspfeilen. Noch offen: Farbzonen als Wahl im freien Baukasten.
- **Vergleichsansichten:** Vorne als Hauptansicht. Sinnvolle Ergänzung später: hinten (Oberkopf und Nacken).
- **Fehlerdarstellung:** umgekehrt gesetzt, zu harter Kontrast.
